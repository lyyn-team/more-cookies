MORE COOKIES — PASTA PRONTA PARA HOSPEDAR (com modo offline)

O que tem aqui
  index.html            o site (leve, ~150 KB)
  sw.js                 service worker: faz o site abrir sem internet
  manifest.webmanifest  permite "Adicionar à tela inicial"
  _headers              configuração da Netlify (sw.js e index.html sempre atualizados)
  assets/img/           fotos e imagens (guardadas para uso offline)
  assets/icons/         ícones do app
  assets/videos/        os 6 vídeos (.mp4) — NÃO ficam guardados offline (são pesados)

Como publicar (qualquer hospedagem de site estático)
  1. Extraia o .zip primeiro. Você precisa ver a pasta aberta, com o index.html dentro.
  2. Envie o CONTEÚDO da pasta (index.html, sw.js, manifest, _headers e assets/), não o .zip.
     - Netlify Drop (app.netlify.com/drop): arraste a pasta inteira.
     - Vercel / Cloudflare Pages / GitHub Pages: suba como projeto estático (sem build).
     - Hostinger / cPanel: coloque tudo em public_html/, com o index.html e o sw.js na raiz.
  3. O site precisa abrir em HTTPS (todas as hospedagens acima já fazem isso). Sem HTTPS o modo offline não liga.

Como o modo offline funciona
  - Na primeira visita COM internet o site guarda no aparelho a página, as fotos e as fontes.
    Só depois disso ele abre sem internet. A primeira visita nunca funciona offline.
  - Sem internet dá para navegar, ver cookies, lojas, momentos, montar o carrinho (ele fica salvo no aparelho).
  - Fazer o pedido (iFood / WhatsApp), abrir mapas e links externos precisa de internet: o site avisa e mantém os itens.
  - Os vídeos mostram a foto de capa quando está offline.

Para publicar uma versão nova
  - Troque os arquivos e mude o valor de VERSION no começo do sw.js (qualquer texto novo).
    Sem isso, quem já visitou pode demorar para ver a mudança.
  - Para trocar uma foto/vídeo, substitua o arquivo em assets/ mantendo o mesmo nome.
